## JSON from the Mac app imports

`app/test/fixtures/mac_export_v6.json` is a real export, written by the Swift `DataExport.export` (schema 6). It holds a list, a note and a daily note with a mood, a task with a weekly rule and a subtask with a colour, tags, a daily series with an exdate, a task block, a goal and a done goal block, a manual link, a setting and a PNG blob.

`data_export_test.dart` group "JSON from the Mac app":
- imports every item (counts, list emoji, goal target, image bytes `[0,1,2,255,254]`);
- keeps the details (rule, summary, day, parent, colour, goal id, done time, exdate, mood, tags, setting, backlink);
- search works after the import;
- imported rows get `deleted = 0` and no user.

"the file has the same rows and columns as a Mac export": import the Mac file, export again. Same tables, same rows, same keys, same values. So the Mac app can read a Flutter export.
