## CI

- Run 38079903666 (commit 580c5d4): macOS green. Linux (Android job) and Windows red: 9 golden pictures of the Tasks panel were different (0.21 % to 0.56 % of the pixels, limit 0.2 %).
- Cause: text on parts of a pixel. A Material text field and a Material dialog add a gap between letters (0.5 and 0.25), the test helper `pumpPane` gave the Material text style, and the names in `Segments` sat on half points. Such text has thin seams between its letters, and each OS draws them in its own way.
- Fix: no letter gap in the fields and in the dialog, whole-number widths in `Segments`, the text style of the shell in `pumpPane`, and the guard `textOffPixels` in each golden test. The limit of the comparator is not changed. The 21 pictures were made again.
- Run 38086903069 (commit 027f849): the steps "Test" (all 1588 tests, with the 21 pictures) and "Build" are green on Android, Windows, macOS and iOS. The step "Integration test" (Track B's device test of the planner, 5 tests) is green on Windows, macOS and iOS.
- Not green in that run: the step "Integration test" on Android. 4 tests pass. 1 test fails: "resize: the bottom edge changes the end" (`app/integration_test/planner_test.dart:194`, expected end 780, actual 750). The push run 38086899962 gives the same result. The test and the planner are Track B's. This was the first time that the test ran on Android: before commit 027f849 the emulator did not start on CI and the step never ended. The request to Track B is in `docs/tracks.md`.
- Run 38089300547 (commit 1cc29a8, 2026-10-10, the run of PR #9 after the merge of `origin/feat/xp-screens` with Track B's fix `020bf05`): all 4 jobs are green, and every step in them: "Test", "Build" and "Integration test" on Android, Windows, macOS and iOS. The Android device test passes 5 of 5 now. The cause was in the app, not in the test: the edge of a block took a finger too late on Android (`docs/tracks.md`, Track B's answers).
