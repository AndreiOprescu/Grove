## Tests that changed shape

- Theme: the store has no colours. Swift checks of `colorScheme` are checks of `appearance` in Dart.
- Images: the store works with bytes only. "data that is not an image is refused" is `loadImage('nope') == null`. "a stored image comes back and is cached" is "a stored image comes back" (same bytes; null after delete).
- `UserDefaults.standard` shared by two stores is one shared `MemoryPrefs`.
- Time: tests that wait for a timer wait for real time (toast, linger, reminder refresh).
